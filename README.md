Kuthe Bappa
===========

Where is Bappa? A cinematic, mobile-first 3D map of famous Mumbai Ganpati pandals for Ganeshotsav 2026.

Ganpati Bappa Morya. Mangal Murti Morya.

Ganeshotsav 2026
----------------
Ganesh Chaturthi: Monday 14 September 2026 (IST)
Visarjan / Anant Chaturdashi: Friday 25 September 2026 (IST)

How to run
----------
Install Node packages in this folder, then start the Next.js app:

  npx next dev

Production:

  npx next build
  npx next start

Stack
-----
Next.js App Router, TypeScript, Tailwind CSS, MapLibre GL JS, OpenFreeMap Liberty tiles.

No Mapbox or Google billed API key. No backend. Deployable on Vercel.

The map starts over Lalbaug (south-central Mumbai), pitch about 60, bearing about -20.
Custom glowing markers. Lalbaugcha Raja is the king.

Add-a-mandal notes stay in the browser only.

Please treat the festival with respect.
